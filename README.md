# Types Roma Funding

TypeScript types library for Roma Funding LLC project.

## Installation

```bash
npm install
```

## Build

```bash
npm run build
```

## Watch Mode

```bash
npm run watch
```

## Project Structure

```
src/
├── consts/      # Constants and configuration
├── enum/        # Enumerations
├── interfaces/  # TypeScript interfaces
├── types/       # TypeScript types
└── utils/       # Utility types and functions
```

## Usage

```typescript
import { /* your types */ } from 'types-roma-funding';
```
